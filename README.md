## ✿ Get started

```
1. Put index.html, style.css, and script.js in one folder
2. Open index.html in your browser
3. Click Start Game
```

Edit a file, save it, refresh the page. That's the whole loop.

---

## ✿ The game at a glance

| | |
|---|---|
| **Goal** | Score as many points as you can |
| **Lives** | 3 |
| **Time** | 45 seconds |
| **Enemy** | The bee 🐝 (it follows you!) |
| **Power-up** | The butterfly 🦋 |

### Controls

| Move | Keys |
|------|------|
| Up | <kbd>W</kbd> or <kbd>↑</kbd> |
| Left | <kbd>A</kbd> or <kbd>←</kbd> |
| Down | <kbd>S</kbd> or <kbd>↓</kbd> |
| Right | <kbd>D</kbd> or <kbd>→</kbd> |

### Flowers

| Flower | Points |
|:------:|:------:|
| 🌸 | 1 |
| 🌷 | 2 |
| 🌻 | 3 |

### Butterfly boost

A butterfly flutters in after 5 seconds, then again every 10 seconds. Touch it and Bunny moves at double speed for 5 seconds.

| Score | Result |

| 30+ | Garden expert 🌻 |
| 15+ | Blooming garden 🌷 |

## ✿ Make it yours

- [ ] Change the title and the background color
- [ ] Swap Bunny for a different emoji
- [ ] Change `timeLeft` to make the game longer or shorter
- [ ] Change `bunnySpeed` to make Bunny faster or slower
- [ ] Change the butterfly boost strength and how long it lasts
- [ ] Change how often the butterfly shows up
- [ ] Add a new flower to the `flowers` list
